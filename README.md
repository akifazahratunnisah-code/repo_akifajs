#  Eksplorasi & Latihan GUI (Java Swing)

Repository ini berisi latihan dan eksplorasi pemrograman berbasis **Graphical User Interface (GUI)** menggunakan Java.

---

##  Tujuan Latihan
Latihan atau eksplorasi GUI dilakukan dengan mencoba membuat komponen-komponent berikut:

- **Top-level Container Class**
- **Intermediate Container Class**
- **Atomic Component Class**
- **Layout Classes** *(minimal 2 Layout Classes atau lebih)*
- **Event Listener** *(Event Method Override dari Event Listener Interfaces atau Event Adapter Classes)*

---

##  Rincian Komponen GUI

| Kategori Komponen | Komponen yang Digunakan | Keterangan |
| :--- | :--- | :--- |
| **Top-level Container** | `JFrame` | Jendela utama aplikasi |
| **Intermediate Container** | `JPanel`, `JScrollPane` | Panel pengelompokkan form & log output |
| **Atomic Component** | `JLabel`, `JTextField`, `JComboBox`, `JButton`, `JTextArea` | Elemen UI interaktif |
| **Layout Classes** | `BorderLayout`, `GridLayout`, `FlowLayout` | Pengaturan tata letak komponen |
| **Event Handling** | `ActionListener`, `WindowAdapter` | Menangani aksi tombol & event jendela |
